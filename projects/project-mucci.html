Project Mucci.

A production cohort mentorship platform with daily progress check-ins, image-annotated feedback, and automated Firebase RBAC security tests.

Live Firebase-authenticated entry portal at project-mucci.web.app.

The Challenge

Cohort mentorship programs routinely fragment across chat threads and spreadsheets, leaving mentors without structured visibility and mentees without consistent feedback loops.

What I Built & Directed

Project Mucci is a mentor-and-mentee command center engineered in React, TypeScript, and Firebase. Mentors launch cohorts, onboard members via invite links or Google OAuth, review daily check-ins, and annotate visual feedback.

Key Proof & Outcomes

  • Implemented strict role-based access control using Firebase Auth, Firestore rules, and Storage rules.
  • Backed membership boundaries and member-removal authorization with automated Vitest security test suites.
  • Live on Firebase Hosting with Google OAuth and invitation-based onboarding.

Core Features & Architecture

  • Cohort program creation with Google OAuth and email-invitation onboarding
  • Daily mentee progress check-ins with status tracking and mentor review queues
  • Direct image-annotation feedback tools for clear visual critique
  • Production Firebase Auth, Firestore membership schema, and Vitest security test coverage
