03 — SAAS / MENTORSHIP PLATFORM

Project Mucci.

A cohort mentorship command center for running structured programs, reviewing daily check-ins, and delivering image-annotated feedback with Firebase RBAC.

ACTUAL DEPLOYED CAPTURE · LIVE — Live authentication entry portal at project-mucci.web.app (Google OAuth & invitation-gated cohort onboarding).

Overview

Project Mucci gives mentors and cohorts a dedicated workspace for daily accountability. Mentors create programs, invite cohorts securely, track daily mentee check-ins, and return annotated visual feedback—backed by Firebase authentication, Firestore membership rules, and automated authorization tests.

The Problem

Mentorship cohorts frequently scatter across messaging apps and shared spreadsheets, making it difficult to enforce program membership boundaries, track consistent daily progress, or preserve structured feedback over time.

Product Concept

Build an invitation-gated mentor-and-mentee command center where daily progress logs, visual critique, and strict Firestore access controls live in a single reliable workspace.

Approach & Implementation

Engineered the frontend in React, TypeScript, and Vite backed by Firebase Auth, Firestore, and Storage rules, with Vitest authorization tests validating program access and member removal.

Key Features

  • Cohort program setup with Google OAuth and email-invitation onboarding
  • Daily mentee progress check-ins with status tracking and mentor review queues
  • Mentor feedback supporting direct image annotations for visual correction
  • Firebase authentication, Firestore-backed membership schema, and Storage security rules
  • Vitest security and authorization tests covering program access and member removal

Challenges & Decisions

Assignments, grading, and analytics modules were intentionally kept locked in the current build so core check-in workflows and Firestore authorization boundaries could be hardened first.

Outcome & Current Status

Deployed live on Firebase Hosting (project-mucci.web.app) with public source and authorization tests documented in GitHub.
