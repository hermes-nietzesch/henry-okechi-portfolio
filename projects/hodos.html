Hodos.

A conversational AI career-navigation app integrating the Anthropic API, Netlify serverless functions, and Airtable.

Visual identity for Hodos — guided career pathways powered by Claude.

The Challenge

Ambitious talent entering the AI economy face overwhelming noise and generic advice that ignores their existing strengths and local market realities.

What I Built & Directed

Hodos guides users through a structured conversational assessment, calling serverless Anthropic Claude endpoints to synthesize tailored career directions, pinpoint skill gaps, and recommend starter projects—persisted via Airtable.

Key Proof & Outcomes

  • End-to-end serverless AI pipeline connecting frontend assessment flows to Anthropic Claude and Airtable.
  • Structured prompt engineering that outputs actionable skill-gap maps instead of generic advice.
  • Fast multi-page web architecture (index, assessment, results) built for global accessibility.

Core Features & Architecture

  • Conversational career-strengths and goals assessment workflow
  • Serverless Netlify Functions orchestrating Anthropic Claude API calls
  • Personalized career-fit summaries, skill-gap diagnostics, and starter project blueprints
  • Airtable integration for structured response persistence
