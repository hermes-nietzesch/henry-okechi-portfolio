08 — AI / CAREER TECHNOLOGY

Hodos.

An AI career-direction web application combining conversational assessment, personalized pathways, skill-gap diagnostics, and serverless Anthropic & Airtable functions.

CONCEPTUAL EDITORIAL PLATE · SOURCE ON GITHUB — Editorial visual plate representing Hodos's guided AI career-pathway architecture (codebase inspected on GitHub).

Overview

Hodos is built for people entering the AI economy who want clarity on where their existing strengths fit. A guided conversational assessment routes through serverless Netlify Functions calling the Anthropic API to generate tailored career pathways, skill-gap breakdowns, and starter projects, persisted in Airtable.

The Problem

Generic career advice ignores individual backgrounds, actionable skill gaps, and locally relevant opportunities in fast-moving AI markets.

Product Concept

Guide users through a lightweight multi-step web assessment (index, assessment, results) backed by structured Claude prompts and Airtable persistence.

Approach & Implementation

Implemented the frontend flow in HTML, CSS, and JavaScript connected to serverless Netlify Functions integrating the Anthropic API and Airtable.

Key Features

  • Conversational strengths and career-direction assessment workflow
  • Serverless Netlify Functions orchestrating Anthropic Claude API calls
  • AI-generated personalized direction summaries, skill-gap diagnostics, and starter project ideas
  • Airtable integration for structured assessment persistence

Challenges & Decisions

Keeping the frontend dependency-free while isolating Anthropic API keys inside Netlify Functions created a fast, auditable serverless architecture.

Outcome & Current Status

Functional codebase published publicly on GitHub (hermes-nietzesch/hodos-site); public deployment pending.
